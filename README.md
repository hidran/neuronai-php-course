# Nested objects and typed arrays

Source and verified exercise for **Agentic AI in PHP with NeuronAI**.

Use PHP 8.5 or later. Run `composer install` in this folder. For live model calls, copy `.env.example` to `.env` locally and supply your own provider credentials. Keep `.env` out of Git.

The project layout is ready to run; `files/` also preserves the original lesson examples and variants.

Available examples:

- `php examples/35-nested-objects.php`
- `php examples/exercise-nested-objects.php`
