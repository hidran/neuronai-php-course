# The project: composer init, PSR-4, NeuronAI, phpdotenv and the environment check

Source code of the lesson "The project: composer init, PSR-4, NeuronAI, phpdotenv and the environment check" of Agentic AI in PHP with NeuronAI.

This branch is the course project at the end of the lesson. It contains everything the earlier lessons built, and its last commit adds only what this lesson changes after "Optional: the same setup with Docker (PHP 8.5, Composer, MariaDB)": compare it with the parent commit to see the lesson's work.

## Setup

Use PHP 8.5 or later.

```bash
composer install
```

## What this lesson changes

- `composer.json`
- `examples/00-check-environment.php`
- `src/.gitkeep`

## Run

- `php examples/00-check-environment.php`
